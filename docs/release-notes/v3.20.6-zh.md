# CC Switch Pro v3.20.6

基于自维护已发布版本 v3.20.5（6d85b22）的定点热修复，仅包含一项行为修复，无数据库变更。

## 本次修复：官方额度耗尽后第三方渠道发送按钮被锁死（#7490）

### 现象

「保留官方登录」打开时切到第三方供应商后，一旦官方 ChatGPT 账号额度（5 小时 / 周限额）耗尽，Codex TUI 弹出 "Usage Limit reached" 锁死会话，ChatGPT 桌面 App 的发送按钮禁用、并降级到 Luna Reserve 流程——即使模型请求已经全部路由到第三方也无法发送。

### 根因

第三方卡上的 `requires_openai_auth = true` 并不决定请求鉴权（带 `experimental_bearer_token` / `env_key` 的卡由注入的 token 完成鉴权），但它会让 Codex 把会话当作官方 ChatGPT 登录，在启动 / 会话开始时执行**官方账号用量检查**。额度耗尽 → 客户端进入锁定态。此前版本在「保留官方登录」开启时每次切换都会把该标志强制盖成 `true`，因此手动改回也会在下次切换时复发。

### 修复内容

- 对所有带 bearer token / `env_key` 的第三方卡，切换与接管写入时一律写 `requires_openai_auth = false`（#7490 作者实测验证的组合：token 独立完成鉴权，不再触发官方用量检查，桌面版不再降级 Luna Reserve）。
- 官方登录仍完整保留在 `auth.json`：桌面版的模型可见性门控、远程操作与官方插件不受影响；代价仅为保留的官方 token 不再经 Codex 自动刷新，失效后重新登录官方即可。
- 官方 ChatGPT 中转卡（消费 OAuth token、不携带 bearer token）与 keyring / auto 凭证存储模式的卡**不受影响**，行为保持。

### 升级后如何生效

1. 升级到本版本后，在 CC Switch 里**任意切换一次 Codex 供应商**（切走再切回目标渠道即可）——存量配置会在这次写入时自愈为 `false`。
2. **完全退出 ChatGPT / Codex App（含托盘）后重新启动**——App 仅在启动时读取 config.toml。
3. 官方额度耗尽期间即可正常通过第三方渠道发送。
