# CC Switch Pro v3.20.5

基于自维护已发布版本 v3.20.4（6545ad6），按主题合并上游 main（f3b18df..e0f70019）共 68 个提交。保留 CC Switch Pro 的应用标识、安装身份、深链、更新源和签名公钥；不覆盖历史发布标签，也不引入上游的赞助商预设与营销类改动。

## 本次更新

### Codex / 官方 ChatGPT 模板修复（重点）

- Codex OAuth 客户端身份从 0.153.4 升级到 0.155.0，ChatGPT 账号登录后可正确显示并选择 GPT-6 Sol / Luna。
- 官方登录态（TOML 无 `model_provider`）下，代理地址改写为内置 provider 的 `openai_base_url` 覆盖：此前写在顶层 `base_url` 上会被 Codex 忽略，导致请求绕过本地代理直连 api.openai.com。
- 接管时自动恢复过期的托管账号绑定；live 快照无凭证时保留已存储认证。
- 新版 Codex CLI 已移除顶层 `disable_response_storage` 配置并在启动时报 "unrecognized configuration setting" 警告：现在每次写入/恢复 live 配置时自动剥离存量配置中的该键（自愈），新建供应商模板不再写入，用户手册同步更新。
- 新建供应商与深链导入模板不再输出该废弃键。

### Codex / 代理协议修复

- 为 GPT-6 Sol/Luna、GPT-5.6 与 GPT-6 Astra 保留 max reasoning effort；grok-4.x（x≥5）家族纳入 effort 白名单，grok-4.6 的 xhigh 原样透传。
- Codex↔Chat 协议转换更健壮：缺失 tool description 不再序列化 null、提升 additional_tools 载体、归一化 detail:original 图片给严格 Chat 网关、合并相邻 commentary 与待发工具调用、钳制低于下限的 max_tokens、跳过 Anthropic SSE 中的空 reasoning_content。
- Images API 流式响应现在会解析 `image_generation.completed` 事件顶层的用量数据（补齐本地代理的计费统计缺口）。
- rollout 会话用量检测：跳过未变化的尾部、以持久化字节游标跟踪增长中的文件。
- GitHub Copilot 场景剥离 stop 参数解锁 auto 模式分类器；模型列表容错非智谱形态字段、支持智谱 OpenAI Responses 列表。
- 更新器：Codex 独立安装版改为重跑官方安装器原地升级（此前退回 `npm i -g` 会另装一份）；Homebrew Cask 用 `brew upgrade --cask`；npm dist-tags 使用专用端点并遵守探测超时。

### 新功能

- 新增 MiniMax Code（mcode）编码代理 harness 支持：预设、安装/升级检测、删除后状态刷新与 Pi 模型兼容透传。
- OpenCode：从获取的模型列表中搜索并批量添加所选模型。
- Claude Desktop：支持 Linux 第三方配置及 DeepSeek V4 的 1M 上下文档位。
- 用量：请求日志与详情面板显示每秒输出 tokens；托管 Codex 卡片在托盘显示绑定的 ChatGPT 账号配额。
- Claude：供应商编辑器新增“禁用 Artifact 工具”快捷开关；隐藏会话 URL 归因。
- Skills：放宽归档条目上限让大仓库可安装；支持 skillId 与目录名不一致的安装与更新。

### 预设与定价

- Kimi 预设切换为原生 Responses 直连（无需本地协议转换），目录更新为 kimi-k3（1M 上下文、并行工具调用）。
- 按官方 Responses API 审计刷新 CN 预设：Bailian 目录加入 Qwen3.8 系列（2.4T A95B / 27B）、智谱 GLM 加入支持视觉的 glm-5.3-flash、MiniMax 端点迁移 minimax.cn 并默认 M3。
- 新增定价种子：Grok 4.7、GLM-5.3-FlashX、Claude Opus 5.5、新 Anthropic / OpenAI 定价，DeepSeek V4 Pro 价格修正。
- 遵循自维护预设策略：不重新引入商业中转/合作伙伴预设与推广文案。

### 其他修复

- WSL：探测工具版本时忽略 shell 启动输出；OpenCode 目录在 WSL 侧时正确检测统一配置。
- 供应商通用同步保留子元数据；外部编辑 prompts 后刷新 active prompts；切换应用时重置供应商滚动位置；非激活品牌图标去饱和；窗口 `show()` 前重置 skip_taskbar。

## 升级前须知

1. **先备份数据库及客户端配置。** 本次无数据库 schema 变更，但涉及认证与配置写入路径更新，升级前备份仍是惯例。
2. 已有 Codex 供应商配置中的 `disable_response_storage` 无需手动处理：任意一次切换后自动剥离；若不想等，可手动删除该行。
3. 使用 ChatGPT 官方登录的用户如看不到 GPT-6 Sol / Luna，请重新登录一次以刷新模型目录。

- Linux x86_64 / ARM64：对应架构的 `.AppImage`、`.deb` 或 `.rpm`

macOS `.tar.gz`、`.sig` 和 `latest.json` 用于自动更新，无需手动安装。

此 fork 的 macOS 构建默认未启用 Apple Developer 签名与公证，首次打开可能受到 Gatekeeper 限制；Tauri updater 使用独立的 minisign 签名验证。
