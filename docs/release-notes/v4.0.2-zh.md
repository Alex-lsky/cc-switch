# CC Switch Pro v4.0.2

基于上游 v4.0.1（全新界面、聚合模式、关键字段写入引擎）的 fork 首个 v4.0 版本，移植了 v3.20.x 发布线的全部自维护定制。数据库 schema v18 → v19 自动迁移，v3.20.8 用户可直接升级。

## 本次更新

### 上游 v4.0 基座

- 全新侧边栏界面与橙色主题；应用页顶部「直连 / 路由 / 聚合」三模式标签。
- **聚合模式（Stack）**：把多家供应商的模型放进 Claude Code 或 Codex 的同一个模型选择器，按模型分发请求，支持同一会话内换模型、上下文压缩跨供应商接续。
- **关键字段写入引擎**：切换供应商由全量重写改为关键字段替换，保留用户与客户端自有配置。
- 会话阅读器重写、用量仪表盘重做（全时段热力图、分页、速度估算）、托盘按应用重组、应用页集中管理各 CLI 工具版本与升级。

### fork 定制移植

- **Me-zai 内置渠道**：8 个应用预设置顶显示（mezai 专属图标），模型目录照抄维护者实时清单（gpt-6-sol + xhigh 默认，13 个模型逐模型推理档位）。
- **官方额度感知（#7490）**：带自有凭据的第三方卡切换后一律不触发官方用量检查（官方额度耗尽不再锁死发送）；切换/接管完成后后台探测官方限额，窗口未满时自动恢复桌面 App 左下角账户显示与官方 token 刷新。探测令牌经认证中心管理器自动刷新，长期 false 期不卡探测。
- **废弃配置键治理**：所有模板停发 `disable_response_storage`（新版 Codex CLI 已移除该键并告警），存量配置在切换时自动剥离自愈。
- **WSL 增强**：配置目录指向 WSL 发行版（含映射盘符经 QueryDosDeviceW 反解）全路径识别；设置页可一键列出 WSL 发行版并生成建议路径；无法加锁的 state 数据库自动跳过。
- **重置 Codex 登录状态**：设置页新增恢复操作（v4 模式架构语义版）——退出路由/聚合、清除登录凭据与托管账号、切回 OpenAI Official，用于登录态损坏的强制恢复。
- **Images API 流式用量解析**：`image_generation.completed` 事件的顶层用量现在计入统计。
- **预设中立化**：不包含上游新增的赞助商/商业中转预设与推广文案（延续 v3.20.x 的厂商中立策略）。

## 升级前须知

1. **先备份数据库及客户端配置**（`~/.cc-switch/`）。首次运行将数据库 schema 从 v18 升至 v19，旧版不能直接打开升级后的数据库。
2. 界面与 v3.20.x 完全不同：首次打开会有一段迁移说明，常用入口（MCP、Skills、提示词、会话、用量）已移入侧边栏。
3. **#7490 行为说明**：升级后在 CC Switch 里任意切换一次 Codex 供应商 + 完全重启 ChatGPT App。官方额度在窗口内时账户显示自动恢复；耗尽期间保持隐藏但第三方发送全程可用，额度重置后下次切换自动恢复。
4. 若官方登录 token 已过期，在 Codex 里重新登录一次官方即可。

## 下载

- Windows x86_64：`CC-Switch-v4.0.2-Windows.msi` 或 `CC-Switch-v4.0.2-Windows-Portable.zip`

- Linux x86_64 / ARM64：对应架构的 `.AppImage`、`.deb` 或 `.rpm`

macOS `.tar.gz`、`.sig` 和 `latest.json` 用于自动更新，无需手动安装。

此 fork 的 macOS 构建默认未启用 Apple Developer 签名与公证，首次打开可能受到 Gatekeeper 限制；Tauri updater 使用独立的 minisign 签名验证。
