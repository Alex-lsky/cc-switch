# CC Switch Pro v3.20.4

基于自维护已发布版本 v3.20.3（bf550c0），合并上游至 f3b18df。保留 CC Switch Pro 的应用标识、安装身份、深链、更新源和签名公钥；不覆盖历史发布标签。

## 本次更新

- 合入 Codex OAuth 账号身份隔离、重复账号检查、重新登录流程与 Provider 切换兼容修复。
- 合入 Codex 原生 Responses、Grok/xAI、Kimi/Moonshot schema、图片生成/编辑代理和并行工具调用修复。
- 合入增量会话用量扫描、自动/手动扫描模式、模型能力和价格种子更新、Otty 终端支持及更新检查错误提示改进。
- 保留自维护的 Codex 登录状态重置、用户自有配置保护、Me-zai 预设、Windows/WSL 路径和退出清理改动。
- 供应商预设按自维护策略整合：保留已有供应商选择与中性链接，吸收官方 Token Plan/QwenCloud 等新增配置，不重新引入已移除的商业中转预设；Pi 保留此前独立的预设集合，不在本次扩展新增赞助渠道。
- 修复合并后统一供应商同步可能把旧 live 地址回填到新配置的问题，同时保留用户自有字段。
- 发布前校验四处版本号、fork 身份、全平台安装包和 updater 签名；所有产物及 latest.json 上传至草稿后再公开，避免发布不完整更新。

## 升级前须知

1. **先备份数据库及客户端配置。** 首次运行将数据库 schema 从 v17 升至 v18；旧版不能直接打开升级后的数据库。回退需要同时恢复升级前的数据库与配置备份。
2. 旧版添加的托管 ChatGPT 账号可能需要在认证中心原账号行点击“重新登录”。不要用“添加账号”代替原位重新登录，以免产生新账号记录而旧绑定仍不可用。
3. 第三方 Codex Provider 的切换与认证写入规则已更新。“保留官方登录”关闭时，第三方直切会删除 auth.json；保留登录需求请检查该设置。旧的无 key/借用官方认证配置可能被拒绝，需要修正 Provider 配置。
4. “重置 Codex 登录状态”仍是主动退出与恢复操作，会清除托管及原生认证状态；不是无感迁移操作。

## 下载

- macOS（Intel / Apple Silicon 通用）：`CC-Switch-v3.20.4-macOS.dmg` 或 `CC-Switch-v3.20.4-macOS.zip`
- Windows x86_64：`CC-Switch-v3.20.4-Windows.msi` 或 `CC-Switch-v3.20.4-Windows-Portable.zip`
- Windows ARM64：`CC-Switch-v3.20.4-Windows-arm64.msi` 或 `CC-Switch-v3.20.4-Windows-arm64-Portable.zip`
- Linux x86_64 / ARM64：对应架构的 `.AppImage`、`.deb` 或 `.rpm`

macOS `.tar.gz`、`.sig` 和 `latest.json` 用于自动更新，无需手动安装。

此 fork 的 macOS 构建默认未启用 Apple Developer 签名与公证，首次打开可能受到 Gatekeeper 限制；Tauri updater 使用独立的 minisign 签名验证。
