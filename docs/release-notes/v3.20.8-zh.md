# CC Switch Pro v3.20.8

基于自维护已发布版本 v3.20.7（7ae4029），从上游 v4.0.x 摘取 14 个可独立应用的 Rust 侧修复。上游同期发布了大版本 v4.0（全新界面、聚合模式、关键字段写入引擎）；其中依赖 v4.0 新架构（Stack 模式、tray 重写、会话管理器重写）的 6 个修复不适用于本发布线，已跳过。

## 本次修复

### Codex / 官方模型

- OAuth 客户端身份升至 0.159.0，支持 GPT-6.1 Sol（#7806），并补充其定价种子。
- 第三方供应商目录中命中 OpenAI 官方的 GPT 行为后续版本特性，本版未包含（依赖 v4.0 的官方模型探测链）。

### 本地路由 / 代理

- 保留终端 web search 输出的顺序（#6509）。

### MCP 同步

- 不再向 Codex `mcp_servers` 写入 `type` 字段（#7735）。
- url-only 的 Codex MCP 规格按 HTTP 传输写入，transport-only 字段与命令型规格分开处理。
- 单个服务器同步失败不再阻塞其余服务器的投射。

### 会话与用量

- 支持 OpenCode V2 SQLite 架构（会话管理器 #7755、用量查询 #7541），V2 消息按 seq 排序并兼容 V1/V2 混合库（#7765）。
- 父子进程 Codex 同步不再因缓存投毒而死锁。

### 数据与 WSL

- 数据库 incremental vacuum 回收整个 freelist。
- Codex 配置目录指向 WSL 发行版（`\\wsl$` / `\\wsl.localhost`，含映射盘符反解）时，跳过 Windows 无法加锁的 state_*.sqlite（9P 重定向器无字节锁，此前会导致历史迁移反复重试、会话扫描卡住）。
- OpenCode 导入/同步保留供应商字段（#7577）。

## 升级后须知

无数据库 schema 变更，直接覆盖升级即可。

## 下载

- macOS（Intel / Apple Silicon 通用）：`CC-Switch-v3.20.8-macOS.dmg` 或 `CC-Switch-v3.20.8-macOS.zip`
- Windows x86_64：`CC-Switch-v3.20.8-Windows.msi` 或 `CC-Switch-v3.20.8-Windows-Portable.zip`
- Windows ARM64：`CC-Switch-v3.20.8-Windows-arm64.msi` 或 `CC-Switch-v3.20.8-Windows-arm64-Portable.zip`
- Linux x86_64 / ARM64：对应架构的 `.AppImage`、`.deb` 或 `.rpm`

macOS `.tar.gz`、`.sig` 和 `latest.json` 用于自动更新，无需手动安装。

此 fork 的 macOS 构建默认未启用 Apple Developer 签名与公证，首次打开可能受到 Gatekeeper 限制；Tauri updater 使用独立的 minisign 签名验证。
