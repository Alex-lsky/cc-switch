# CC Switch Pro v3.20.7

基于自维护已发布版本 v3.20.6（fc399df）的定点热修复，恢复 v3.20.6 后丢失的官方账户状态显示，无数据库变更。

## 本次修复：官方账户状态显示回来了（#7490 后续）

### v3.20.6 的副作用

v3.20.6 为解决「官方额度耗尽后第三方渠道发送按钮被锁死」，把带 bearer token 的第三方卡一律写成 `requires_openai_auth = false`。账户显示与用量检查是同一面旗的两面——false 在解除锁定的同时，也让桌面 App 左下角不再显示官方账户状态（且官方 token 不再自动刷新）。

### v3.20.7 的方案：额度感知的动态盖章

- **写入路径仍然默认 `false`**（安全态）：切换永远可用，官方额度耗尽期间做出的切换绝不会锁住发送。
- 每次切换 / 开启接管完成后，CC Switch 在后台用保留的官方登录查询 ChatGPT 限额（`chatgpt.com/backend-api/wham/usage`，3 秒超时）：
  - **所有限额窗口均未达 100%** → 自动把 live 配置提升回 `true`：账户显示、官方 token 自动刷新全部恢复——此时额度可用，探查不会锁定会话；
  - **任一窗口已达 100% 或查询失败** → 保持 `false`：不显示账户状态，但第三方发送全程可用，直到额度窗口重置后的下一次切换。

### 效果

- 额度正常时：账户状态显示 + token 刷新 + 第三方路由，与官方体验一致。
- 额度耗尽时：切一次供应商（cc-switch 里任意切换），发送立即可用；额度重置后下次切换账户显示自动恢复。

### 升级后如何生效

1. 升级到本版本后，在 CC Switch 里**任意切换一次 Codex 供应商**。
2. **完全退出 ChatGPT / Codex App（含托盘）后重新启动**。

若官方登录 token 已过期（查询失败会一直保持 false、无账户显示），在 Codex 里重新登录一次官方即可。
